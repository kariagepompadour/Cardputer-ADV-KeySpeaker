# Pico AUX ユニット: 確認できた事実と、箱に印字してよいこと

English: [AUX_PICO2_BOX.md](AUX_PICO2_BOX.md)。配線と製作手順: [AUX_PICO2_BUILD_JA.md](AUX_PICO2_BUILD_JA.md)。設計: [AUX_PICO2_DESIGN_JA.md](AUX_PICO2_DESIGN_JA.md)

印: ✅ このリポジトリのコードで確認、または作者が実測。🟡 予想または一般知識。⛔ 未確認。

## 1. Grove ケーブルが運ぶもの

| Cardputer の表示 | 線(作者のケーブル) | 運ぶもの | Pico 側 | 根拠 |
|---|---|---|---|---|
| `G1` | 黄 | UART、Pico → Cardputer(音とダイヤルのフレーム) | GP0(TX)。330 Ω 経由 | ✅ `KeySpeaker_S0.ino:1602`(RX = GPIO1)、`AuxPico2.ino:23` |
| `G2` | 白 | UART、Cardputer → Pico(命令 `KS?` `KS+` `KS-`) | GP1(RX)。330 Ω 経由 | ✅ `KeySpeaker_S0.ino:1602`(TX = GPIO2)、`AuxPico2.ino:23` |
| `5V` | 赤 | 電源、Cardputer → ユニット | VSYS(39番)と PCM1808 の VDD | ✅ 設計書 §4 |
| `G` | 黒 | GND | GND | ✅ 設計書 §4 |

- **I²C ではなく UART** です。8N1、**2,000,000 bps**、3.3 V ロジック(✅ `AuxFrame.h:17`。同じファイルが両方のファームにあります)。
- 音は一方向(Pico → Cardputer)。48 kHz、16 bit、モノラル、5 ms ごとに 240 サンプル、CRC-16 付き。
- 同じ 2 本は、任意のジョグダイヤルの I²C にも使われます。同時に開くのは片方だけです(✅ `KeySpeaker_S0.ino:1590`)。
- 線の色はケーブルごとに違います。色ではなく、ポートの横の `G`、`5V`、`G2`、`G1` の表示で合わせてください。

## 2. 電源

- ユニットは **Grove の赤線から給電**されます(✅ 設計書 §5。負荷時に約 5.1 V を実測)。消費は 5 V で約 100 mA(🟡 設計上の値)。
- 使用中、Pico 自身の USB は**不要**です。プログラムの書き込み(BOOTSEL)と状態表示用です。
- **Cardputer 自身の USB と Grove は一緒に使えます**(✅ Grove 赤線を USB 接続時に 5.347 V と実測し、その状態で音も出しています)。下の規則は **Pico 側の USB** だけの話です。
- **Grove ケーブルと Pico の USB を同時につながないでください。**(✅ 製作ガイド §2)両方が VSYS に給電します。Pico 2 には USB(VBUS)から VSYS へのダイオードがあるので Pico 自身は守られます(🟡 Raspberry Pi のデータシート。このリポジトリにはありません)。ただし**両方をつないだ状態を作者は一度も測っていません**(⛔)。危険は、USB の電流が Cardputer の 5 V 端子へ逆流することです。
- 赤線は Pico 2 の VSYS 上限 5.5 V 以下でなければなりません。Cardputer は 5.0〜5.35 V(✅ 実測)で、余裕は約 0.15 V です。それより高い電源から給電しないでください。
- Cardputer ADV では、`PORT.A` の横のスイッチを `5VOUT` にします。

## 3. パソコンから見えるもの

✅ `AuxPico2.ino` が開くのは `Serial`(USB CDC、115200 bps)だけで、1 秒ごとに状態を 1 行出します。USB オーディオのコードはありません。

つまり USB 経由では、Pico は**シリアルポート(COM ポート)**として見え、**サウンドカードとしては見えません**。音を USB でパソコンへ送ることはしません。「Line-in → USB」という表記は誤りになります。音が出ていくのは Grove の UART だけです。

## 4. Cardputer ADV 専用の部分はあるか

| 部分 | Cardputer 専用か |
|---|---|
| Pico のファーム(`AuxPico2`) | いいえ。Cardputer のことを何も知りません。3 つの命令に答えてフレームを送るだけです。 |
| フレーム形式(`AuxFrame.h`) | いいえ。CRC 付きの普通の UART フレームです。 |
| KeySpeaker の受信側 | **ピン番号が直書き**です(`Serial1.begin(..., 1, 2)`、`Wire.begin(2, 1, ...)`)。プログラム全体が Cardputer ADV 用です(M5Cardputer ライブラリ、ES8311、キーボード、画面)。 |

よって **KeySpeaker 自体は Cardputer ADV 専用**です。ただしユニットは汎用です。

## 5. 他のボードについて書いてよいこと

条件付きで可:

> 「3.3 V の UART を持ち、5 V(5.5 V まで、約 100 mA)を供給でき、ユニットのプロトコル(2 Mbps UART、`AuxFrame.h` 参照)を話せるホスト。動作確認は Cardputer ADV 上の KeySpeaker のみ。」

不可: 「どの ESP32 でも動く」「つなぐだけで使える」。他のボード向けのソフトはありません。`KS?` / `KS+` を送ってフレームを読むプログラムが必要です。2 Mbps を確実に扱えるかも未確認です(⛔)。5 V ロジックのホスト(例: Arduino Uno)は危険です。Pico のピンは 3.3 V です。

## 6. 製作マニュアルに足す項目

1. 配線表(§1。色ではなく表示で)。
2. 電源の警告(§2): Grove と USB を同時につながない、5.5 V 上限、`5VOUT`。
3. 対応ボード(§5)。「確認したのは〜のみ」の書き方で。
4. パソコンからの見え方(§3)。
5. トラブル対処の追加: 「AUX にならない: G1 と G2 の取り違えを確認」、「Pico 自身の USB と Grove を両方つないだとき Cardputer が再起動する・画面が暗くなる: すぐ Pico の USB を抜く」。
6. はんだ付け版の点検(§7)。
7. 電源と GND の作り方は 2 通りあります。ブレッドボード版のマニュアルは + と − のレールを使うので、PCM1808 基板の I²S 側の GND も − レールにつなぎます。作者のコンパクトな箱にはレールがなく、Grove の赤と黒をそれぞれ 2 本に分けて(Pico と PCM1808 基板へ)、Pico の AGND(33 番)と基板の CN3 の GND(R_IN と L_IN の間の真ん中のピン)を 1 本の線でつないでいます。I²S 側の GND のピンは空きのままで、この形で動いています(作者の個体。動く理由は測っていません)。マニュアルには、箱は同じ配線のレールなし版だと書きます。

## 7. 初めての箱入り製作の点検(作者向け)

接続のほとんどは差し込み式のジャンパ線です。はんだを使ったのは、Grove ケーブルを分岐して 2 本の 330 Ω につなぐ部分だけです(はんだ部分に熱収縮チューブ)。2026-11-09 の作者の写真から読んだものです。⛔ = 写真では判断できない。

- 差し込み式(デュポン)コネクタは摩擦で止まっているだけで、箱を動かすと抜けかけることがあります。ホットボンドを少量か、テープ 1 周で押さえてください。特に 5 V と GND。⛔

- ばらばらのジャンパ線の束は、揺れて Pico のピンや ADC 基板に触れて短絡することがあります。結束バンドかホットボンドで固定してください。⛔
- 5 V、GND、I²S の 3 本など、隣り合う露出したはんだ部分には絶縁(熱収縮チューブか小さなテープ)が要ります。⛔
- より線のはんだは、1 本ずつ軽く引いて確認します。つやがなく丸い盛りは冷えはんだの疑いがあります。溶かし直してください。⛔
- Grove ケーブルは箱から出る所にストレインリリーフ(内側の結び目、切り欠き、クランプ)が要ります。引っ張られるとはんだが剥がれます。⛔
- 蓋の溝は深く作ってある(作者)ので、レールに線がはさまることはなさそうです。ただし 2026-11-09 の写真では、線の輪が箱の縁より高くはみ出しています。蓋が輪を Pico のピンや基板に押し付けます。線を短くするか束ねて、すべて縁より下に収めてください。
- 初めて電源を入れる前に、電源オフでテスターの導通ブザーで 5 V と GND が短絡していないか測ります(製作ガイドの手順のまま有効)。
- Grove の 2 本の 330 Ω は、はんだ付け版にも必ず残してください。
- Grove の出口に 5V と GND の表示を付けて、逆向きに挿せないようにしてください。

**作者の写真で確認したこと(2026-11-09、写真のために箱を開けた状態)。** Pico の micro-USB コネクタは四角い穴の中に、PCM1808 基板のジャックは丸い穴の中に収まっています。2 枚の基板は、それぞれの部屋にある 4 つの小さな爪が、取り付け穴に合う位置です(爪が穴に入っているかは見えませんでした)。330 Ω の抵抗は、橙・橙・茶の帯です。Grove の赤と黒の分岐は、熱収縮チューブで覆われ、むき出しの線は見えません。`AUX_PICO2_DESIGN_JA.md` の第 4 章の接続表は、全項目を作者の説明と照らして一致しました。`Fn+I` で AUX が出るので、Grove の 2 本の線は、向きも正しくつながっています。蓋を閉めて Cardputer を蓋の上に載せた状態、ジャックの穴に 3.5 mm プラグが入っている状態、Grove ケーブルが切り欠きから出ている状態は、作者の写真(IMG_6753、IMG_6754)で見ました。Pico の USB 穴に micro-USB プラグが、ジャックの穴に 3.5 mm プラグが付いた状態は、IMG_6771 で見ました(USB プラグは挿さっているように見えますが、どこまで入っているかは、角度から分かりません)。彫り文字は印刷されていて、その写真でも読み取れますが、白地に白で薄く、下のほうの行は、その角度では読みにくいです。

## 8. 箱に入れる文字(作者の計画、CASE4 のモデル、2026-11-09)

Cardputer ADV は蓋の上に載ります(直径 4 mm のピン 2 本が背面の穴にはまります)。そのため蓋の上面は隠れます。文字は側面に、3D プリンターで彫ります。機器の名前は汎用のままにし、KeySpeaker は対応ソフトとして書きます。

| 場所 | 文字 |
|---|---|
| 穴のない長い側面(大) | `PICO AUX` |
| 同じ面(小) | `Line-in → Grove`、`Compatible: KeySpeaker` |
| 丸いジャックの穴の脇 | `AUX IN` |
| Grove の切り欠きの脇 | `TO CARDPUTER`(ジョグダイヤルを通すときは `DIAL` を追加してもよい) |
| Pico の USB 穴の上 | `PICO 2 USB`、`SET UP ONLY`、`UNPLUG GROVE`、`FIRST`(4 行) |

使わないもの: 「Line-in → USB」(Pico は USB でサウンドではなくシリアルポートとして見えるため)、「for Cardputer ADV」(ADV 専用に読めるため。ユニット自体は汎用です)。Cardputer が重なる帯には文字を入れません。

**USB の文字について。** Grove をつないだまま Pico 自身の USB をつなぐ場合は、測っていません(Cardputer 自身の USB と Grove の同時使用は問題ないと分かっています)。この文字は「壊れる」という主張ではなく、手順の指示です。製作マニュアルにも、同じ警告を載せます。

**彫り込み。** 文字はすべてネガティブパーツ(Bambu Studio の操作は「カット」)で、深さは 0.5 mm にそろえます。CASE4 のモデルでは、2 つの長い側面とも 0.49 mm で、壁の厚みは 2 mm です。小さい文字は太字にしました。まだ確認していないこと: A1 mini(ノズル 0.4 mm)で、いちばん小さい文字(`Compatible: KeySpeaker`)の試し印刷。前面の文字の一部は、モデルの上で壁の角から約 0.2 mm のところにあります。
